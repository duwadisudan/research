# Research site

Source for https://duwadisudan.github.io/research/, a single-page site that explains three projects from my PhD:

- Decoding spatial attention in the cocktail party problem with whole-head high-density fNIRS (NeuroImage, 2026)
- Listening effort (in progress)
- An internship project on empathy in speech

`python build.py` assembles the partials in `src/` into `docs/index.html`, the page GitHub Pages serves. It needs only Python 3.
